# Verification Experiment Scripts

This directory contains helper scripts to run batch LTL\X verification experiments using **DSS-Checker** (`distributedstatespace`) and **LTSmin**.

## Prerequisites

- **DSS-Checker** (`distributedstatespace` executable in the working directory or specified via the `BIN` environment variable) for `run_mc.sh`.
- **LTSmin** binaries (`pnml2lts-seq`, `pnml2lts-sym`, `etf2lts-seq`) located in the working directory for `verif_all.sh`.
- **Perl** (used by `ltl2action.sh` for formula conversion).
- **GNU time** (`/usr/bin/time`, from the `time` package) to measure peak memory usage (RSS) in `verif_all.sh`.

---

## 1. Model Checking with DSS-Checker (`run_mc.sh`)

The script `run_mc.sh` runs LTL\X verification using `distributedstatespace` on a modular Petri net model (`.pn`) and an LTL property file (`.ltl`), saves the full program output to a timestamped log file, and prints a formatted summary table reporting:
- The **DSS construction duration**.
- For each property: its ID, target module, verification status (`VERIFIEE` / `VIOLEE`), verification duration (s), and formula.
- Total number of properties checked, verified, and violated, along with the total verification time.

### Usage

```bash
./run_mc.sh <model.pn> <properties.ltl> [additional_options...]
```

- `<model.pn>`: Modular Petri net model file.
- `<properties.ltl>`: File containing one or more LTL\X formulas.
- `[additional_options...]` *(optional)*: Extra flags forwarded to `distributedstatespace` (e.g., `--fairness`, `--no-reduction`).
- Environment variable `BIN`: Path to the `distributedstatespace` binary (defaults to `./distributedstatespace`).

### Examples

```bash
./run_mc.sh ERK10.pn erk_all.ltl
./run_mc.sh ERK10.pn erk_all.ltl --fairness --no-reduction
BIN=../cmake-build-debug/src/distributedstatespace ./run_mc.sh ../samples/ERK/ERK10.pn ../samples/ERK/erk_all_m1.ltl
```

### Output

Full execution logs are saved to `mc_<model>_<properties>_<YYYYMMDD_HHMMSS>.log` in the current directory.

## 2. Converting LTL Formulas for LTSmin (`ltl2action.sh`)

The script `ltl2action.sh` takes an `.ltl` file containing one LTL formula per line, converts every transition identifier `t` into `(action == "t")` (while preserving LTL operators/keywords `U`, `R`, `W`, `M`, `X`, `F`, `G`, `V`, `true`, `false`, and already-quoted strings), and writes each converted formula into its own file (`prop1.ltl`, `prop2.ltl`, ...) inside an output directory.

### Usage

```bash
./ltl2action.sh <file.ltl> [output_dir] [model.pnml]
```

- `<file.ltl>`: Input file containing one LTL formula per line.
- `[output_dir]` *(optional)*: Output directory for the generated `prop*.ltl` files (defaults to `<filename>_props`).
- `[model.pnml]` *(optional)*: If provided, checks that every transition referenced in the formulas exists in the PNML model and warns about any missing transitions.

### Example

```bash
./ltl2action.sh ../samples/ERK/erk_all_m1.ltl erk_props ../samples/ERK/ERK1.pnml
```

## 3. Verifying Properties with LTSmin (`verif_all.sh`)

The script `verif_all.sh` checks all `prop*.ltl` properties in a directory against a PNML Petri net model using LTSmin, recording execution time, explored states and transitions, peak memory usage (MB), and verification results.

### Usage

```bash
./verif_all.sh [model.pnml] [props_dir] [mode]
```

- `[model.pnml]`: Path to the PNML model file (default: `ERK1.pnml`).
- `[props_dir]`: Directory containing `prop*.ltl` files generated by `ltl2action.sh` (default: `erk_props`).
- `[mode]`: Verification mode (default: `volee`):
  - `volee` *(on-the-fly)*: Runs `pnml2lts-seq` to verify each property on the fly directly on the PNML model.
  - `complet` *(full state space)*:
    1. Builds the complete state space into an ETF file using `pnml2lts-sym` and counts total states and transitions with `etf2lts-seq`.
    2. Verifies each property on the constructed ETF state space using `etf2lts-seq`.

### Example

```bash
# On-the-fly verification
./verif_all.sh ERK1.pnml erk_props volee

# Full state-space construction followed by verification
./verif_all.sh ERK1.pnml erk_props complet
```

### Output

Results are written to `resultats/<model>_<props_dir>_<mode>/`:
- `resume.txt`: Summary table reporting the verification time (s), explored states and transitions of the product automaton, peak memory (MB), and status (`VÉRIFIÉE`, `NON VÉRIFIÉE`, or `ERREUR`) for each property.
- `logs/`: Detailed LTSmin logs (`prop*.log`, `construction.log`, `comptage.log`) and memory measurement files (`*.mem`).
- `contre_exemples/`: Counterexample traces (`ce_prop*.gcf`) for falsified properties.
